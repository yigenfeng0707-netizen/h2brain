第1页：背景与真实问题

行业背景

氢能重卡是交通领域脱碳的关键路径。北京大兴国际氢能示范区作为国家级氢能产业集聚区，已聚集数十家氢能产业链企业，形成了从制氢、储氢、运氢到用氢的完整产业生态。氢能重卡在实际运营中，单车氢气成本占运营总成本的40%以上，远高于柴油车的燃油占比（约25%），因此运营效率的每一点提升都意味着真金白银的节约。

四大真实痛点

痛点 现状 影响
氢耗高且波动大 百公里氢耗8-13kg，同型号车辆差异可达60% 氢气单价30-36元/kg，每多1kg/百公里等于每百公里多花30-36元
加氢难 全国仅约400座加氢站，大兴示范区周边仅5座 单次加氢排队等待平均22分钟，高峰期可达45分钟
成本不透明 氢能/维保/人工/折旧成本缺乏精细核算 车队管理者无法识别成本异常，难以针对性优化
燃料电池衰减不可见 电堆健康状态无实时评估手段 衰减到临界点才报警，维保被动，寿命缩短

数据来源

本项目的模拟数据基于大兴氢能示范区真实场景参数：加氢站坐标、氢气价格（30-36元/kg）、氢能重卡型号（福田智蓝H2-31T、飞驰FSQ-18T、大运氢能-25T、解放J7氢能版）均来自公开产业数据。

第4页：核心功能 — 智能体详解（上）

1. 氢耗优化 Agent (hydrogen_opt)

功能：实时监控每辆车的氢耗，基于载重、路况、天气、驾驶行为推荐最优行驶参数。

技术实现：
- 构建氢耗预测模型：氢耗 = f(载重, 速度, 温度, 坡度, 驾驶行为评分)
- 基于LSTM时序预测未来30分钟氢耗趋势
- LLM生成自然语言优化建议

关键指标：百公里氢耗降低12%（从平均9.6kg降至8.4kg）

示例输出：

京A-H2308 当前百公里氢耗11.2kg，高于车队均值9.6kg。主要原因：瞬时加速频率高于均值35%，建议将巡航速度从75km/h降至68km/h，预计氢耗降至9.8kg/百公里，本趟可节约氢气成本约86元。

2. 路径规划 Agent (route_plan)

功能：融合加氢站分布、剩余氢量、订单目的地，规划最优运输路线。

技术实现：
- 基于OR-Tools求解带加氢约束的车辆路径问题（VRP with Refueling Constraints）
- 续航圈计算：基于剩余氢量和历史氢耗，计算车辆可达范围
- 多站路径择优：对比2-3条候选路线的氢耗、时间、成本

关键指标：续航匹配率98%+

核心创新：首次将加氢站约束纳入车辆路径规划。传统VRP假设加油站充足，而氢能场景中加氢站稀少（全国仅约400座），必须将加氢站位置和氢气库存作为硬约束。

3. 加氢站调度 Agent (station_dispatch)

功能：实时监控各加氢站排队情况，智能分流车辆到最优加氢站。

技术实现：
- 排队论模型（M/M/c）预测各站等待时间
- 强化学习动态分流策略
- 氢价对比：不同加氢站价格差异可达4元/kg

关键指标：等待时间降低60%（从平均22分钟降至9分钟）

第5页：核心功能 — 智能体详解（下）

4. 车队管理 Agent (fleet_manage)

功能：全车队运力统一调度，订单-车辆智能匹配，司机排班优化。

技术实现：
- 多目标优化：同时最小化空驶率、氢耗成本、延误率
- 车队长画像：基于历史订单数据分析各车队运营特征
- MCP协议实现跨系统协同

关键指标：利用率提升25%

5. 成本分析 Agent (cost_analysis)

功能：全成本核算 + TCO对标 + 成本归因分析。

技术实现：
- 全成本模型：氢能成本 + 维保成本 + 人工成本 + 折旧 + 保险 + 路桥费
- TCO对标：与柴油重卡进行全生命周期成本对比
- LLM成本异常归因：自动识别成本异常原因并给出优化路径

关键指标：运营成本降低18%

成本结构示例：
| 成本项 | 占比 | 优化空间 |
|--------|------|---------|
| 氢能 | 42% | 高（氢耗优化+加氢站择优） |
| 维保 | 18% | 中（燃料电池健康预测） |
| 人工 | 15% | 低 |
| 折旧 | 20% | 低 |
| 其他 | 5% | - |

6. 燃料电池健康 Agent (fuelcell_health)

功能：预测燃料电池电堆衰减，提前推荐维保方案。

技术实现：
- 基于电压衰减曲线的LSTM衰减预测模型
- 健康状态分级：优秀(>90%) / 良好(80-90%) / 关注(70-80%) / 预警(<70%)
- RAG检索维保知识库，生成维保建议

关键指标：寿命预测准确率95%+

第8页：创新点

1. 首次将加氢站约束纳入车辆路径规划

传统VRP假设加油站充足，不构成路径约束。氢能场景中加氢站稀少（全国仅约400座，柴油加油站超10万座），必须将加氢站位置、氢气库存、排队时间作为硬约束纳入路径优化。

2. 多智能体协同的全链路优化

不是单点AI应用，而是六个智能体协同覆盖"氢-站-车-路-人-成本"全链路。例如：路径规划Agent发现需要加氢 → 触发加氢站调度Agent推荐最优站点 → 同时通知成本分析Agent预估加氢成本 → 氢耗优化Agent调整行驶参数以延长续航。

3. ReAct推理引擎输出可执行建议

不同于简单的数据可视化或LLM对话，ReAct引擎通过Thought-Action-Observation链式推理，输出结构化的可执行建议（具体到速度调整值、推荐加氢站、预计节约金额）。

4. 港口集卡经验迁移

团队将港口集卡智能调度平台（LogiBrain）的成熟运筹优化经验迁移至氢能场景。LogiBrain已实现空驶率降低15-20%、年节约5-8万/车、98.7%追踪精度的可验证成果，核心调度算法和异常检测框架直接复用。

5. 氢耗预测模型

基于载重、速度、温度、坡度、驾驶行为五因子构建氢耗预测模型，填补了氢能重卡能耗优化领域的空白。
