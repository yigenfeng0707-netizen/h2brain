# 氢智行 H2Brain - 技术架构文档

## 一、系统总览

氢智行 H2Brain 采用五层架构 + 六大智能体的设计，面向氢能车辆运营全场景。

```
┌─────────────────────────────────────────────────┐
│  L5 用户接入层                                    │
│  车队管理 · 司机App · 加氢站终端 · 氢能监管平台     │
│  IoT · 车载OBD · 北斗/高德                        │
├─────────────────────────────────────────────────┤
│  L4 智能体服务层                                   │
│  六大氢能智能体协同 · 总控Agent任务编排             │
├─────────────────────────────────────────────────┤
│  L3 数据与检索层                                   │
│  氢能垂直知识库 · 车辆数字孪生 · 实时运力池         │
├─────────────────────────────────────────────────┤
│  L2 核心技术层                                     │
│  LLM · RAG · MCP协议总线 · 运筹优化 · LSTM        │
├─────────────────────────────────────────────────┤
│  L1 基础设施层                                     │
│  氢能示范区私有云 · 百车级并发 · 等保二级           │
└─────────────────────────────────────────────────┘
```

## 二、六大智能体

### 1. 氢耗优化 Agent (hydrogen_opt)
- **职责**: 实时监控氢耗，基于载重/路况/天气/驾驶行为推荐最优行驶参数
- **技术**: LLM + RAG + 时序预测
- **指标**: 百公里氢耗降低 12%

### 2. 路径规划 Agent (route_plan)
- **职责**: 融合加氢站分布、剩余氢量、订单目的地，规划最优运输路线
- **技术**: 图搜索 + OR-Tools + 高德API
- **指标**: 续航匹配率 98%+

### 3. 加氢站调度 Agent (station_dispatch)
- **职责**: 实时监控排队，智能分流车辆到最优加氢站
- **技术**: 排队论 + 强化学习
- **指标**: 等待时间降低 60%

### 4. 车队管理 Agent (fleet_manage)
- **职责**: 全车队运力统一调度，订单-车辆智能匹配
- **技术**: 多目标优化 + MCP协议
- **指标**: 利用率提升 25%

### 5. 成本分析 Agent (cost_analysis)
- **职责**: 全链路成本拆解（氢能/维保/人工/折旧），多维度分析与优化
- **技术**: OLAP + LLM归因分析
- **指标**: 运营成本降低 18%

### 6. 燃料电池健康 Agent (fuelcell_health)
- **职责**: 基于电堆电压/温度/衰减率预测健康状态与剩余寿命
- **技术**: LSTM时序预测 + 数字孪生
- **指标**: 寿命预测准确率 95%+

## 三、ReAct 推理引擎

系统采用 ReAct (Reasoning + Acting) 模式，支持五类决策场景：

1. **氢耗优化决策** - 分析车辆氢耗异常并给出优化建议
2. **路径规划决策** - 综合氢量/路况/订单规划最优路线
3. **加氢站调度决策** - 多站择优与排队避让
4. **成本分析决策** - 成本异常归因与优化路径
5. **车队管理决策** - 运力调度与排班优化

每个场景的 ReAct 流程：Thought → Action → Observation → ... → Final Answer

## 四、数据架构

- **车辆数据**: 15辆氢能重卡，含位置/氢量/里程/燃料电池健康等
- **加氢站数据**: 5个加氢站（大兴氢能示范区真实坐标），含储氢/排队/价格
- **订单数据**: 10个运输订单，含起终点/货物/时效
- **事件流**: 实时事件推送（低氢告警/加氢完成/故障预警等）
- **KPI**: 9个核心运营指标（车辆数/在线率/氢耗/利用率/成本/碳减排等）
